# Technology Stack Freeze
Approved target stack for SYSTEM Y’INTARA YA BWUZURI:
- Frontend/UI: React + TypeScript
- Windows Desktop: Electron
- Web/PWA: React PWA
- Backend/API: Node.js + TypeScript
- API style: REST
- Central database: PostgreSQL
- Offline/Sync: local client store/database + synchronization layer
- Hosting: Linux VPS + API/Web server + PostgreSQL
- Security: HTTPS/TLS, password hashing, server-side role/scope access control
- Backup: automated PostgreSQL backups
- Mobile: API-connected online-only client
