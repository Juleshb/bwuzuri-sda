# Phase 4 — Budget + Contributions Integration
Status: IMPLEMENTED IN SOURCE (not yet Windows/hosting tested)

Requirements remain frozen. Added:
- User-defined budget periods (no fixed Sabbath 1–4 periods).
- Regional Leader lifecycle: Draft, Active, Completed, Archived.
- Financial and non-financial metrics; QTY/unit-price metadata and sum-only supported.
- Hierarchical target allocations: Itorero, Igihande, Itsinda, Umwizera.
- Financial achievement calculated automatically from Contributions within the budget date range and contribution type.
- Scope-aware progress for Church/Section/Group users.
- Target, Achievement, Percentage, Remaining; achievement may exceed 100%, Remaining floors at zero.
- Manual achievement endpoint only for non-financial metrics, supporting AMAVUNA-style planned/actual metrics.
- Member allocations remain available mainly for Ibirundo and similar requirements.

No approved requirement was intentionally changed.
